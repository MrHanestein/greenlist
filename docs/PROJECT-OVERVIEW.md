# Greenlist project overview

Greenlist is a working local prototype for international graduates seeking UK data analyst roles. It combines evidence about employer licences and vacancy sponsorship policies with application preparation, learning exercises and a review-first browser extension.

## Problem and product

An employer appearing in the sponsor register does not establish that a particular vacancy offers sponsorship. Candidates also repeat application details and may struggle to translate vague requirements into preparation tasks. Greenlist aims to make those uncertainties visible and reuse user-approved experience without inventing personal claims.

## Implemented prototype

- Dated sponsor imports, reviewed employer identities/aliases, separate vacancy evidence and freshness.
- Job-source integrations for Greenhouse, Lever and Adzuna, disabled until configured and permitted.
- Profile, approved application memory, AI application packs with source references and saved revisions.
- Short analyst diagnostics, practice, reassessment and a shared learning plan.
- Written interview rehearsal and optional AI feedback with response quotations and follow-up questions.
- Manifest V3 extension for reviewed autofill on Greenhouse/Lever; never auto-submits.
- Tracker with confirmed-submission snapshots, authenticated private documents, export and deletion.
- Billing integration with closed launch gates, usage limits and conservative AI cost reservations.

## AI use

Anthropic integration is implemented for on-demand application preparation and interview feedback. The model is configurable. Inputs are limited, personal claims reference approved facts, and users review output. Quotas and a shared spending limit constrain use. Automated checks do not prove semantic accuracy; real-provider evaluation remains required. No live API usage, production traffic or commercial traction is claimed in this overview.

## Stage and evidence

The last recorded full local validation passed 68 automated tests, a production build and desktop/mobile browser journeys. Provider calls in tests were mocked. These historical results are not a claim of a fresh run on the day of a programme application.

The supplied register was dated 11 September 2026. Last recorded live-vacancy count was zero. The 100-employer file is a research queue, not completed identity or permission verification. No paid pilot outcome or paying-customer count has been established.
